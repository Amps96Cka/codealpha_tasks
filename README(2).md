# CodeAlpha_MatrixOperations

Task 2 (Medium) of the CodeAlpha C Programming Internship.

A menu-driven program for matrix addition, multiplication and transpose, built with functions and 2D arrays.

## Features
- Matrix addition, multiplication, transpose
- Separate function for each operation (modular design)
- Dimension handling: multiplication asks for compatible sizes automatically
- Supports matrices up to 10 x 10 with input validation

## Compile and run
```
gcc matrix.c -o matrix
./matrix
```

## Sample output (multiplication)
```
A (2 x 3) x B (3 x 2) =
   22    28
   49    64
```
