# CodeAlpha_Calculator

Task 1 (Basic) of the CodeAlpha C Programming Internship.

A console calculator that performs addition, subtraction, multiplication and division using a `switch` statement.

## Features
- `switch-case` operator selection (`+`, `-`, `*`, `/`)
- Division-by-zero protection
- Input validation for numbers and operators
- Repeat calculations without restarting

## Compile and run
```
gcc calculator.c -o calculator
./calculator
```

## Sample output
```
Enter first number : 10
Choose operation (+  -  *  /) : /
Enter second number: 4

Result: 10.00 / 4.00 = 2.50
```
